# v1.0.0 — European Call pricing and numerical research APIs

Release date: 2026-10-03.

## Included

- Validated Python/NumPy and C++ batch price/Delta/Gamma interfaces, with explicit units, shapes, errors and degenerate conventions.
- Public C++ complex-step kernels shared by the experiment executable and library consumers.
- P3 default complex CDF, configurable per call with orders 2–6; propagation through pricing, Greeks, batch APIs, experiments and report scripts.
- Regression coverage for Gamma degenerate inputs, coefficient fixtures, parameter forwarding, broadcasting and local convergence order.
- Repository organization for library code, experiments, notebooks, benchmarks, golden data and versioned artifacts; legacy Python script wrappers retained.
- Automatic Markdown test inventory/report with raw evidence, failure causes, CSV metadata and error curves.
- Mathematical foundation from Gaussian density to erf/erfc, Hermite conventions and the complex CDF expansion; independent high-precision and throughput studies.
- README API examples and guidance for connecting a market-data research system.
- Python dependencies specified as supported major-version ranges; corrected the legacy SciPy version pin. These ranges are not a lockfile and not every version combination has been tested.

## Scope and next steps

v1 supports European Calls with continuous dividend yield. Put, Vega/Theta/Rho, implied-volatility inversion, American exercise/discrete dividends, explicit SIMD, Python/C++ bindings and market-data adapters remain future work. It supplies library imports/linking and research scripts; no hosted API or trading system is included.

P3 is the default on the complex path. Ordinary pricing and risk calculations can use the analytic facade. CDF order does not choose a suitable Gamma step, and passing tests does not mean zero numerical error throughout the input domain.
